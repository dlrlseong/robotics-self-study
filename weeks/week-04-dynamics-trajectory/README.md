# 4주차 · 동역학과 궤적 생성

**핵심 질문.** 토크를 주면 팔이 어떻게 움직이는가(순동역학). 원하는 움직임에 필요한 토크는 얼마인가(역동역학). 그 움직임을 시간 축에 어떻게 얹는가(궤적).
